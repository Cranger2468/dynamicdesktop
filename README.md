# Remix of Remix of Dynamic Island

Create a macOS Dynamic Island desktop app using Electron, React, and Tailwind CSS based on the attached specification. Build a polished, transparent, frameless, always-on-top window pinned to the Mac notch/menu bar area that recreates the look and feel of the iPhone Dynamic Island. Implement smooth black pill-shaped morphing animations with spring physics, supporting compact and expanded states for media playback (track, artist, album art, playback controls), volume and brightness adjustments, microphone and camera privacy indicators, battery and charging status, countdown timers, and notifications. Include an interactive simulation bar to preview and trigger all events, a menu bar tray controller, and a settings panel to configure behavior, positioning, enabled events, and animations.
